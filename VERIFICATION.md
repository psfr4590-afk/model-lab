# Model Lab Verification

## Verification model

Model Lab is not considered verified by pytest alone. Release verification is divided into:

1. Automated contract and behavior tests.
2. Python compilation/static checks.
3. Target-machine environment tests.
4. Human-visible Windows desktop smoke checks.

Vendor tests inside the bundled `llama.cpp` tree are intentionally outside the Model Lab pytest scope.

## Automated tests

The Model Lab suite covers package identity, launcher behavior, navigation registration, screen inventory, pipeline stages, API route contracts, credential presets and encryption paths, backend startup behavior, 1760×990 configuration, dataset/pipeline wiring, service-to-API contracts, secret scanning, documentation, and release-test presence.

Run:

```powershell
python -m pytest -q
```

The exact pass/skip count is generated by the test run. This document does not hard-code an old count.

## Target-machine tests

Run on the actual Windows machine:

```powershell
python -m pytest -q .\tests\model_lab\test_machine_environment.py
```

These tests verify Windows/Python/Tk availability, physical display size, PATH tools, optional NVIDIA visibility, PyTorch CUDA observability, llama.cpp presence, the hardened doctor, Command Center health, and real desktop UI construction/navigation.

Some GPU checks intentionally skip when the machine has no NVIDIA tooling. A skip is not a fabricated PASS.

## Human-visible acceptance

The operator must also visibly verify every navigation surface, dataset selection, stage Run controls, Stop controls, the four credential slots, credential save/replace behavior, the 1760×990 fit, and the absence of unwanted browser launch from the desktop application. These checks are listed in `VERIFICATION_CHECKLIST.md` because a headless test runner cannot honestly certify visual behavior it cannot see.

## Release command

From PowerShell:

```powershell
.\scripts\run_release_verification.ps1 -IncludeMachineChecks
```

Omit `-IncludeMachineChecks` when running away from the target Windows desktop. The script will explicitly report that those checks were not run.
